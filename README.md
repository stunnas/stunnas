## ⚙️ How I Build

I approach independent development as a complete software engineering and product development lifecycle, rather than simply writing code.

My workflow incorporates:

1. **Product Discovery** - Identifying problems, defining requirements, researching existing solutions, and evaluating product opportunities.
2. **Design & Prototyping** - Exploring visual directions, building interactive prototypes, and establishing cohesive design systems.
3. **Technical Architecture** - Defining system boundaries, data models, integrations, reusable components, and engineering standards.
4. **Implementation** - Developing functionality through incremental, agent-assisted engineering workflows.
5. **Knowledge Management** - Maintaining technical decisions, architecture documentation, project context, and reusable engineering knowledge.
6. **Review & Validation** - Specialized code review, deterministic quality checks, automated testing, accessibility, security, and dependency validation.
7. **Release & Distribution** - Preparing documentation, demonstrations, installation processes, deployment pipelines, and release artifacts.
8. **Continuous Improvement** - Evaluating feedback, refining functionality, modernizing architecture, and improving the overall product experience.

I actively use **Claude Code**, **Claude Design**, **Obsidian**, and **Sillplate** throughout this process, combining AI-assisted development with deliberate engineering practices.
